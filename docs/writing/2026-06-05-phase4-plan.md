# Material-LIMS Phase 4 实施计划

> 制定时间：2026-06-05
> 范围依据：`docs/writing/2026-06-04-material-lims-brief.md` 第七节 Phase 4 定义
> 前置完成：Phase 3 (JWT/SSO + Graph + 报告生成 + PDF + 数据权限)，BUILD SUCCESS

## 一、Phase 4 范围

按 brief 第七节 Phase 4「扩展功能」逐条落地：

1. 零部件 / 供应商 API 集成（修补 Phase 3 遗留）
2. 设备维修管理（EquipmentRepair 全栈）
3. 设备状态语义前后端对齐
4. 成本统计看板增强（时间维度 / Item 明细 / 导出）
5. 节假日工作日计算插件
6. i18n 双语后端持久化

## 二、各模块改动清单

### P0 ExternalApiService 修补
- application.yml 新增 `external.api.parts.base-url / suppliers.base-url / mock.enabled`
- ExternalApiService 改用配置 baseUrl，dev 时返回 mock
- 增加 partDetail/supplierDetail 单条查询

### P1 EquipmentRepair 全栈
- entity/mapper/service/controller 全套
- 创建维修单时联动把 equipment.status -> UNDER_REPAIR；完成维修恢复 ACTIVE
- 前端 EquipmentRepairs 页面真实 CRUD

### P2 设备状态对齐
- 前端 EquipmentStatus.tsx 改为 ACTIVE/UNDER_REPAIR/DECOMMISSIONED

### P3 成本统计增强
- DashboardController.costStats 加 startDate/endDate/groupBy(brand|type|month|item)
- 新增 /api/v1/dashboard/cost-export（Apache POI 写 xlsx）
- 前端 CostDashboard 加日期筛选 + 维度切换 + 导出

### P4 工作日 / 节假日计算插件
- lims-common/util/HolidayCalendar：addBusinessDays / isBusinessDay / countBusinessDays
- 缓存全年节假日表
- RequestService.create 用它计算 due_date
- 暴露 /api/v1/holidays/calculate-due-date

### P5 i18n 后端持久化
- SysI18nMessage 实体 + Mapper + Service + Controller
- GET /api/v1/i18n/messages?locale=
- 管理员可维护字典

## 三、不在 Phase 4 范围

移动端适配 / Knowledge Hub 功能 / SharePoint 集成 / 报告模板 docx 实体文件。

## 四、验收标准

1. `./mvnw -DskipTests clean compile` BUILD SUCCESS，零警告
2. dev profile 启动后能调通新增 5 个端点
3. 前端 EquipmentRepairs / CostDashboard 真实可用
